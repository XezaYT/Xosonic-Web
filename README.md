## 🌟 Highlights

- **⚡ Edge Streaming**: Lightning-fast audio playback with automated fallback and adaptive bitrate selection.
- **📁 Native Local Audio Playback**: Drag-and-drop or file upload for `.mp3`, `.wav`, `.flac`, and `.m4a` with browser-native decoding.
- **📜 Synced Live LRC Lyrics**: Real-time karaoke-style lyric highlight engine synchronized down to the millisecond.
- **🌐 Active Radar**: Privacy-preserving active listener telemetry pulse and sound room sync.
- **📱 Unified Ecosystem Portal**: Instant download links for the **Universal Android Release APK**, **iOS Lite IPA**, and **HyperX Discord Voice Bot**.

## 🚀 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Edge Runtime)
- **Styling**: Tailwind CSS & Glassmorphism UI
- **Icons**: Lucide Icons
- **Deployment**: Vercel Edge Network

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/XezaYT/Xosonic-Web.git
cd Xosonic-Web

# Install dependencies
pnpm install

# Start development server
pnpm dev
```
